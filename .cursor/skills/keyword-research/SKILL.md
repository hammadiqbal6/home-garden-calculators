# Keyword research (free tools)

## Workflow
1. Seed from `docs/MARKET-RESEARCH.md` / `docs/ideas/ideas.csv`.
2. Expand with Google Autocomplete (`seed`, `seed for`, `seed a–z`, year).
3. Capture People Also Ask phrasing for FAQ (manual SERP).
4. Check volume/KD manually (Ahrefs free, Semrush free, Keyword Planner)—record source beside every figure.
5. Good target if: KD ≤30 (guideline), SERP shows small tool sites, distinct user task.
6. Assign **one URL per intent** in `docs/KEYWORD-MAP.md`.
7. Put modifiers on the same page (units, bags, brand names)—do not spawn thin variants.

## Output
Update KEYWORD-MAP + propose tool options/FAQ bullets; never invent Nuqti-style volumes as facts.
